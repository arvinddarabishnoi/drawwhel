# Draw Wheal

A browser-based HTML5 drawing-wheel driving game. Draw a custom wheel, mount it on your car, and drive across obstacle-filled levels.

## Run

Open `index.html` in a modern browser, or enable GitHub Pages from Settings → Pages (Deploy from `main` / root).

## Controls
- Draw wheel: use the drawing pad with mouse or touch.
- Drive: `D` / `→` accelerate, `A` / `←` brake/reverse, `Space` jump.
- Mobile: use the on-screen controls.

## Project status
The game is built with vanilla HTML, CSS, Canvas, and JavaScript. Artwork is stored as separate standalone SVG files under `assets/` (not as a combined collage or sprite sheet).
